# Вектор — концепция сайта инспекционной компании

## Условия использования

Демо опубликовано для просмотра и оценки. Использование охраняемых материалов в других проектах требует предварительного письменного разрешения Oleg Baglyukov, кроме случаев, разрешённых законом, условиями GitHub или лицензиями сторонних материалов. Указание автора не заменяет разрешения.

Полные условия: [LICENSE.md](LICENSE.md) · [Страница для посетителей](terms.html). Сторонние шрифты и изображения сохраняют собственные лицензии.

Откройте index.html в современном браузере. Сборка и сервер не нужны.
При разрешённом размещении сохраняйте index.html, terms.html, LICENSE.md и assets/ вместе.
Изображение, шрифт, стили и скрипты работают без доступа к интернету.

Это демонстрационный проект для портфолио: вымышленный бренд, услуги и образец отчёта.
Форма не отправляет данные и не сохраняет их в браузере. После заполнения можно
скачать локальный текстовый черновик. Образец отчёта также скачивается в TXT.

## Состав

- index.html — страница, встроенные CSS и JavaScript.
- assets/ — фотография и шрифт с лицензией.
- preview/ — снимки страницы на компьютере и телефоне (полная страница и первый экран).

## Проверка

Chromium / Playwright, локальное открытие через file://.
Ширины: 320, 360, 390, 600, 768, 850, 1024, 1440, 1920 px.
Проверяются переполнение страницы, локальные материалы, пять услуг,
управление вкладками с клавиатуры, мобильное меню, диалог и Escape,
FAQ, внутренние ссылки, валидация и редактирование заявки, два скачивания.
При отключённом JavaScript кнопка отправки формы недоступна.
